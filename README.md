# ACController

A React + TypeScript web app, built with [Vite](https://vite.dev/).

## Prerequisites

- [Node.js](https://nodejs.org/) 18+ (developed on Node 22)

## Getting started

```bash
npm install       # install dependencies (run once, or after pulling changes)
npm run dev       # start the dev server with hot reload
```

Then open the `localhost` URL printed in the terminal.

## Commands

| Command | What it does |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start the dev server (hot reload) |
| `npm run build` | Type-check and build for production into `dist/` |
| `npm run preview` | Serve the production build locally to preview it |
| `npm run lint` | Run oxlint |

## Project structure

```
src/          Application source (App.tsx, main.tsx, styles, assets)
public/       Static files served as-is
index.html    App entry point
dist/         Production build output (generated by `npm run build`)
```
